# RigApp 0.1.0

The first version: a desktop app for running OpenRig rigs, with each rig as a project and each seat as a thread.

## New

- Projects and threads: every rig in the sidebar, seats grouped by pod, the lead seat marked.
- Chat: each Claude Code seat's conversation read from its session file, live, with tool cards and diffs.
- Send to any seat, pick another with `@`, and approve, deny or stop a seat.
- Overview of what needs you (waiting, errored, finished, working), with unread dots.
- Ctrl+K for every seat and action, and to search every seat's screen log.
- Graph of each rig's pods, seats and links, and each seat's terminal with Take control.
- Specs editor for rig.yaml and CULTURE.md, checked by OpenRig before saving.
- Rig up (with OpenRig's plan first), rig down, snapshots with restore, and Claude usage.
- New project from OpenRig's spec library.
- Files tab: a read-only look at a seat's folder.
- Settings: theme, daemon address, rebindable shortcuts, and optional Memory (Hindsight) and Code (CodeGraph) panels.
- The desktop app updates itself from GitHub releases.
