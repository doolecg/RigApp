Milestone 3 "Specs and lifecycle"

State: Planned (proposed 2026-10-29, not approved)

Read this first
  • Goal: Create and edit rigs from RigApp and control their whole life: up, down, snapshots, restore, adopt, bundles.
  • Out of scope: Seat tools (M5).
  • Nothing here starts until you approve this guide.
  • To change anything, write in the notes box under it, press Copy my notes, and paste to Claude.

1. Parts

  • Spec editor: RigSpec, AgentSpec and CULTURE.md with validation by OpenRig's own validators (/api/rigs/import/validate, /api/agents/validate) and a diff before saving. Saves by export, edit, re-import (stopgap, gap 5).
  • Lifecycle: rig up and down, snapshot and restore, adopt tmux sessions, import and export bundles. A confirm before anything destructive.
  • Snapshot timeline: the rig's snapshots (every 5 minutes on kernel) on a timeline with one-click restore.
  • Usage: each seat's context use and the Claude 5-hour and weekly windows from /api/provider/usage.
  • Search: Ctrl+K searches every seat's log through /api/transcripts/:session/grep.

2. Questions for doole

  1. Monaco or CodeMirror for the editor? Claude recommends: CodeMirror 6: far smaller and loads fast; Monaco is heavy for YAML and Markdown.

4. Review checklist (about 30 minutes)

  • Edit kernel's rig.yaml, see the diff, save, and the change is live after rig up.
  • Rig down asks first and offers a snapshot.
  • Restore from a snapshot on the timeline works.
  • Usage shows real numbers for a Claude seat.
