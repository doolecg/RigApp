Milestone 5 "Seat tools"

State: Partly built 2026-10-29: the Memory and Code panels. Seat-side tools wait (see section 1)

Read this first
  • Goal: Give chosen pods Hindsight memory, CodeGraph and a browser, and let seats and Hindsight use local models, without adding tokens to seats that do not need them.
  • Out of scope: Anything that injects prompts into seats by default.
  • Started 2026-10-29 under your "keep going" instruction. Built first: the parts that are for you and cost seats nothing.
  • To change anything, write in the notes box under it, press Copy my notes, and paste to Claude.

1. Parts

  • Hindsight: (Memory panel built; the MCP for seats waits for the per-pod route below) detect the server, a Memory panel (search, knowledge pages), and the Hindsight MCP for pods you pick.
  • CodeGraph: (Code panel built; the MCP for seats waits for the per-pod route below) detect the CLI, a Code panel (explore a symbol, callers), and the CodeGraph MCP for pods you pick.
  • Browser: (not built: needs @playwright/mcp and WSL mirrored networking on your PC; parked in the bible idea map) Operant's browser brought over: an in-app browser tab seats can drive through @playwright/mcp, with Allow, Allow all, Deny, Take control and an action log; or a headless browser in WSL for background work.
  • Local models: (not built: Hindsight's model is Hindsight's own setting, and OpenRig decides Pi seats' models; parked) any OpenAI-compatible server (Ollama, LM Studio, llama.cpp) for Hindsight, and for Pi seats if OpenRig allows it.
  • Token cost: (both panels are off until you turn them on in Settings, and add nothing to any seat; per-seat costs come with the per-pod route) each tool shows roughly what its tool list costs a seat per turn, and nothing is on until you turn it on.

2. Questions for doole

  1. Approve @playwright/mcp and playwright-core? Claude recommends: yes; Apache 2.0, the same ones Operant uses.
  2. Turn on WSL mirrored networking so seats in WSL can reach the in-app browser? Claude recommends: yes, when you want the in-app browser; headless mode works without it.

3. How to test each step

Step: Memory and Code panels

  1. Open Settings, turn on "Memory panel" and "Code panel" under Tools.
  2. Open a seat: the right panel gains Memory and Code tabs.
  3. Memory: pick the project's bank (RigApp guesses it from the seat's folder), type a question, press Enter: Hindsight's matching memories show.
  4. Code: type a symbol or question, press Enter: CodeGraph's answer for the seat's folder shows.

4. Review checklist (about 30 minutes)

  • Turn on Hindsight for one pod only; other seats' context does not grow.
  • A seat opens a page in the in-app browser and asks before clicking.
  • Hindsight works with a local model.
